# Project Review

## Project

**Name:** Frontier Kingdom

**One Sentence Pitch:** A roguelike where you survive in a frontier kingdom, sending adventuers of on quests


# 1. First Impression
Spend 10-20 minutes using the project without making changes.
- few game screens are still in the old format
- some overlapping elements
- to many keyboard driven actions
- dont need shortcuts at bottom of the page
- no title screen with continue, new game, settings and exit game option
- kingdom actions are duplicated with the top menu, I think we only need the top menu

# 2. Story
Would I keep reading?
- no story yet, a tutorial mixed story would be good, the rest emergent gameplay

# 3. Does it Have Potential?
Ignoring its current state...
Could this become something great with more work?
-I think so, its kinda fun and reminds me of other simliar games, just needs the polish

# 4. Biggest Problems
- the ui is confusing, to many keyboard shortcuts and buttons dont work in every screen.

# 5. Best Parts
What already works well?
- doing a quest works well, a branching path the player can take, is enjoyable
- the combat is also okay, just needs more feedback

# 6. Next Goal
What is the **single most important milestone**?
- make sure the UI is fully mouse driven, we can have shortcuts but they dont need to be always visible.

# 7. Content Notes (Optional)
Would this make an interesting YouTube video or livestream?
- I think so, simliar games have been pretty popular.
